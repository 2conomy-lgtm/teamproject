# Team Lens (팀 렌즈) 👥

> **"다름을 점수화하지 않고, 상호존중을 위한 협업 대화를 설계합니다."**

본 애플리케이션은 팀원 상호 간 소통 선호도와 의사결정 방식의 다름을 건강하게 인지하고, 프로젝트 킥오프 전 관계 조율을 위한 대화의 장(Ground Rules Workshop)을 설계하도록 돕는 교육 및 퍼실리테이션 보조 한국어 웹 앱입니다.

---

## 🛡️ 개인정보 보호 및 데이터 수집 제로 원칙 (Privacy by Design)

본 프로젝트는 수강생 실습용 교육용 도구로서, 인적 프라이버시 침해를 사전에 원천 예방하는 설계 철학을 고수합니다.

1. **네트워크 서버 전송 제로 (Serverless Processing):**
   - 작성하시는 모든 팀 이름, 구성원 별칭, MBTI 성향 코드는 어떠한 외부 중앙 수집 서버나 트래커로 전송되지 않습니다.
   - 모든 분석 연산은 전적으로 **사용자 기기(Client-side) 브라우저의 런타임 보안 세션 메모리 상에서만 일회성으로 가동**됩니다.
2. **별칭(가명) 입력 최적화:**
   - 임직원의 법적 실명 정보를 입력하지 않고, 상호 인지 가능한 자유로운 닉네임이나 별칭(예: 민수, 루카스 등)을 기입하여 분석하는 사용법을 강력히 장장합니다.
3. **분석 결과 익명화 마스킹 기능:**
   - 결과물 텍스트 복사 시 실제 입력한 이름조차 노출되지 않기를 희망할 경우, 입력 폼 하단의 **[결과 화면 익명화 마스킹]** 옵션을 체크하여 **"팀장", "팀원 1", "팀원 2"** 등으로 완전히 익명화 가공된 분석서를 얻을 수 있습니다.
4. **로컬 스토리지 보존의 자발적 통제권:**
   - 기본적으로 새로고침 시 데이터가 완전히 증발되는 보안 세션 상태를 가집니다.
   - 단, 사용자가 기기 상의 편리한 정보 보존을 허용하기 위해 **"이 기기에 입력값 임시 캐싱 허용"**을 명시적으로 체크(Opt-in)한 경우에 한해서만 `localStorage`에 데이터를 안전하게 임시 보관합니다.
   - 언제든 **[🗑️ 기기 보존 캐시 완전 파기]** 버튼을 통해 흔적 없이 물리적 영구 파기(Purge)할 수 있는 제어권을 사용자에게 넘깁니다.

## ⚖️ MBTI 모델 분석의 이론적 한계와 사용 주의보

본 앱에서 제공하는 모든 텍스트 조합 피드백은 MBTI 선호 유형 지표에 수록된 보편적인 인지 패턴 경향성을 설명할 뿐입니다.

*   **낙인 효과 및 결정론의 기피:** 
    *   MBTI 성향은 개인의 영속적인 고정 불변한 특징이 아니며, 인간의 입체적 가능성을 다 설명할 수 없습니다. "이 사람은 무조건 ~다" 라는 단정적 규정을 일절 회피합니다.
*   **인사 오용 절대 금지 서약:**
    *   본 리포트 결과물 및 약속 카드는 소통 윤리적 다양성을 조명하기 위함입니다. 이를 **채용 배제, 부서 배치 타당성 심사, 업무 능력 등급 분류, 승진 가부, 성과 평가**의 객관적 근거로 절대 악용하거나 활용하여선 안 되며 오용 방지를 지향합니다.
*   **우열의 배제:**
    *   성향 조합 간 점수화(궁합), 어떤 유형이 어떤 유형보다 탁월하다거나 부실하다는 우열 평가는 일절 수록되어 있지 않으며 논리적으로 불가합니다. 다름의 교차점 소통 가이드만 수록됩니다.
